# Communication Skills Club

A weekly meetup focused on improving soft skills and communication — vocabulary,
public speaking, and structured peer feedback.

## When

Every **Sunday, 4:30 PM EST**.

## Format

Each session follows the same general agenda (see [AGENDA_TEMPLATE.md](AGENDA_TEMPLATE.md)):

1. **Word of the Week** — 5 new English words assigned the prior week. Every
   member explains each word's meaning and uses it in a sentence.
2. **Topic Presentations** — each member presents a short topic of their
   choosing to the group.
3. **Feedback Round** — the group gives each presenter constructive feedback.
4. **Next Week's Words** — pick the next 5 words to learn before the following session.

## Structure

- `AGENDA_TEMPLATE.md` — reusable template copied into each new session folder.
- `sessions/YYYY-MM-DD/` — one folder per session:
  - `agenda.md` — that week's agenda and the 5 assigned words.
  - `topics.md` — who presented what.
  - `feedback.md` — feedback notes for each presenter.

## Starting a new session

Copy `AGENDA_TEMPLATE.md` into a new `sessions/YYYY-MM-DD/agenda.md` (use that
Sunday's date), then fill in the week's words and presenters.
