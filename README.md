# Communication Skills Club

A weekly meetup focused on improving soft skills and communication — vocabulary,
public speaking, and structured peer feedback.

## When

Every **Sunday, 4:30 PM EST**.

## Format

The standing rules for every session live in
[WEEKLY_EXPECTATIONS.md](WEEKLY_EXPECTATIONS.md):

1. **5 things round** — everyone brings 5 words, idioms, phrases, or other
   communication-related items, and explains each with an example.
2. **Topic presentation** (optional) — anyone who wants to can present a
   short topic that week.
3. **Feedback round** — the group gives each presenter constructive feedback.

## Structure

- `WEEKLY_EXPECTATIONS.md` — the standing rules/format for every session.
- `sessions/YYYY-MM-DD/` — one folder per session:
  - `agenda.md` — that week's agenda, the 5 items per person, and presenters.
  - `topics.md` — who presented what.
  - `feedback.md` — feedback notes for each presenter.

## Starting a new session

Create a new `sessions/YYYY-MM-DD/` folder (use that Sunday's date) with
`agenda.md`, `topics.md`, and `feedback.md`, following the format in
`WEEKLY_EXPECTATIONS.md`.
