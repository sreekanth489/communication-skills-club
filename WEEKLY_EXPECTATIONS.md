# Weekly Expectations

The standing rules for every session — what to bring, what's optional, and how
the hour runs. Copy the relevant parts into each `sessions/YYYY-MM-DD/agenda.md`.

## 1. Everyone brings 5 things

Each member comes prepared with **5 items** that help build communication
skills. These don't have to all be the same type — mix and match:

- New words
- Idioms or expressions
- Phrases or sayings
- Anything else interesting related to communication (a rhetorical device,
  a public-speaking tip, a common grammar mistake, etc.)

For each item, explain what it means and use it in a sentence (or a short
example) so the group sees it in context.

## 2. Topic presentation (optional)

Anyone who wants to can present a short topic to the group that week —
doesn't need to happen every session. If you're presenting, let the group
know ahead of time (or at the start of the session) so it can be added to
that week's agenda.

## 3. Feedback round

After the 5 items are shared and any presentations wrap up, the group gives
each presenter feedback — what worked, what to improve.

## Session flow

1. **Vocabulary/idiom round** — each person shares their 5 items with examples
2. **Topic presentation(s)** — if anyone signed up that week
3. **Feedback round** — group feedback for each presenter
4. **Next week** — confirm who's presenting next, if known
